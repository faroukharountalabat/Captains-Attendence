🔗 Google Sheets Setup
Do this once — takes about 5 minutes
1
Create a Google Sheet
Open sheets.google.com → click the big + to create a blank sheet. In the address bar you'll see a long URL — copy the part between /d/ and /edit. That's your Sheet ID.
2
Open Apps Script
Inside your Sheet click Extensions in the top menu → Apps Script. A new tab opens with a code editor. Delete everything in it.
3
Paste the backend code
Open the Code.gs file from your download. Copy everything inside it. Paste it into the Apps Script editor. Find the line that says YOUR_GOOGLE_SHEET_ID_HERE and replace it with your real Sheet ID. Press Ctrl+S to save.
4
Run setup once
In the function dropdown (shows "myFunction") select setupSheets then click the ▶ Run button. Accept any permission dialogs. This creates all the sheet tabs automatically.
5
Deploy as Web App
Click Deploy (top right) → New deployment → click the gear icon → choose Web app. Set Execute as: Me. Set Who has access: Anyone. Click Deploy. Copy the long URL that appears — that's your Web App URL.
6
Paste URL below and connect
Come back here, paste the Web App URL in the field below, and tap Connect. Done — all data now syncs to your Sheet.
🌐 How to host this app (free)
So riders can open it on their phones
1
Go to Netlify Drop
Open app.netlify.com/drop in your browser. No account needed.
2
Find the app folder
Unzip the file you downloaded from Claude. Open the folder called talabat-attendance → then open the folder called app. You'll see 3 files inside: index.html, manifest.json, sw.js.
3
Drag the folder onto Netlify
Drag the entire app folder onto the Netlify Drop page. In a few seconds you get a free URL like https://happy-name-123.netlify.app. Share that link with your riders — they can open it in Chrome and tap "Add to Home Screen" to install it like an app.
